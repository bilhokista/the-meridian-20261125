# The Meridian — 25 November 2026

An illustrated English-language front page covering six stories across trade,
spaceflight, diplomacy, courts, coastal weather and disaster response. The
illustrations are editorial drawings, not depictions of the exact locations,
people or equipment involved. All shapes and lettering are rendered by the
entry itself; it contains no downloaded images or fonts.

## Render

Run `python3 main.py` to write `/output/entry.png`. To preview without writing
to `/output`, run `MAKEFUN_OUTPUT_DIR=/tmp/meridian python3 main.py`.
The Python standard library is sufficient. No network, input assets, clock,
or random values are used at runtime.
